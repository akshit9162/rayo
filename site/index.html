    How ranking works

    1. Crawl agent links. Seeds are the community list, sites proposed in its pull requests and agent manifests on GitHub. From each site Wayfind follows partner network URLs, links.json and allowed_peers.
    2. Match the job. Text match over descriptions, sample queries, agent descriptions and action names picks the candidates.
    3. Order on evidence. Behaviour probes (30%), spec conformance (25%), links from other sites (15%), live reads shared with any caller (10%), real actions (10%), a published can't-do list (5%) and freshness (5%).
    4. Demote what looks wrong. A served definition that does not match its declared digest (×0.2), an expired claim (×0.5), text aimed at other agents or rankers (×0.3) or a near-copy of a higher-ranked site (×0.5).

    Other agent sites can call Wayfind's network at this folder + wayfind. Its searches are shared with every site.
